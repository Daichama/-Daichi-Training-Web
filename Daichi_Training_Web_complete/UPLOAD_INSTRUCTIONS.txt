GitHub Webでの反映手順

1. このZIPを展開する
2. GitHubのリポジトリを開く
3. Daichi_Training_Web フォルダを開く
4. Add file → Upload files
5. 展開した Daichi_Training_Web_complete の中身をアップロードする
6. Commit changes
7. Vercelのデプロイ完了を待つ

主要な置換ファイル:
- app/page.js
- app/style.css
- app/api/workouts/route.js
- app/api/sync/route.js
- app/lib/sync.js（新規）

既存のVercel環境変数は変更不要です。
