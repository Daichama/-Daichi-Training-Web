# D-log v6.0

トレ中の入力速度と柔軟性を強化した更新版です。

## v6.0 の主な変更
- トレ全体メモ、種目別メモ（Notionのメモへ保存）
- Master登録済み種目の追加、今日だけスキップ
- 種目順の入れ替え
- Standard / Short / Home バリエーション
- レストポーズ追加レップ入力
- 終了時の「しんどさ・充実度・パンプ」5段階評価
- Toastを上部へ移動し、レストタイマーとの重なりを解消
- 途中入力の自動保存・復元

## 注意
種目追加はNotionのMaster DBに登録済みの種目から選びます。これによりExercise Logのrelationを維持します。
HomeはMaster内の種目名からマシン系を除外して構成し、該当種目がない場合は先頭4種目を使用します。

Vercelでは既存プロジェクトへフォルダ内容を上書きし、Environment Variablesを維持して再デプロイしてください。
