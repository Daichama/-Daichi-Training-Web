# D-log v8.0.0

v7.0.1のUIをベースに、日常操作をD-log側へ寄せた更新版です。

## 主な変更
- 週間予定をD-log上で変更・保存
- 今日を強調した7日カレンダー表示
- 予定は端末に保存し、`NOTION_SCHEDULE_DS`設定時はNotionにも同期
- 自動生成の種目コメント・目標文を廃止
- ユーザー入力の種目メモを種目マスターへ保存し、次回表示
- 現セットのハイライトを大幅に強化

## デプロイ
従来どおりGitHubへ配置し、Vercelでデプロイしてください。既存のNotion環境変数を利用します。

## 注意
この実行環境にはnode_modulesが含まれていないため、ここでは`next build`を完走できていません。Vercelのビルドログで最終確認してください。
