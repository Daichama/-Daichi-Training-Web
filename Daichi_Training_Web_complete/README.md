# D-log v9.0.0

D-logだけで入力・履歴確認・種目別進捗確認まで行えるNext.jsアプリです。Notionは裏側のデータ保存先として利用します。

## v9追加
- 履歴タブ
- Progressタブ
- Workout結果詳細
- 種目別トップセット・最高重量・推定1RM・ボリューム推移

既存のVercel環境変数をそのまま利用してください。


## v9.2.0
Homeは週間予定、履歴タブは予定編集可能な月間トレーニングカレンダーです。予定は薄色、実績は部位色と「済」スタンプで表示します。


## v9.3.2
種目の最初のセットを完了した時刻を基準に実施順を自動保存し、履歴もその順番で表示します。Notion側で順番を手入力する必要はありません。
