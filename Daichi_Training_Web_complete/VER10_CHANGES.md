# D-log Ver.10.0.0

- シンプルなビジュアル重視ホームへ刷新
- 画面下部に Home / Workout / History / Progress / Menu の固定ナビゲーションを追加
- 今日の部位、今週予定、開始ボタンをホームの主役に変更
- 開始前メニューを長押し・ドラッグで並べ替え可能に変更
- Progressを「種目 / ボリューム / Body / 写真」のタブ構成へ変更
- 部位別ボリュームにトレ回数、セット数、目標値、達成率を追加
- 履歴の月別折りたたみ、種目名編集、完了表示など既存Ver.10改修を維持
- DLOG_SESSION_ID等のデバッグ文字列は通常表示しない

## Note
写真アップロード本体と部位別目標値の編集画面は、UI導線と表示枠を先行実装しています。
