# D-log Changelog

## v7.0.1

### Added
- Workout中に新しい種目名・部位・セット数を入力してNotion種目マスターへ登録
- 新規登録した種目を現在のWorkoutへ即時追加
- iPhoneで振動APIが使えない場合の押下アニメーション

### Clarified
- iPhone Safari/PWAではVibration API非対応のため、Web版だけではネイティブ触覚を出せない


## 7.0.0 — 2026-08-03

### Added
- ホームに今週（月〜日）のトレーニング予定を表示
- 日本時間で「今日」を正しくハイライト
- トレーニング中に種目を追加し、その場でセット入力欄を生成
- 現在入力すべきセットを `NOW` とアクセント枠でハイライト
- 種目ごとのセット進捗バーと完了数を表示
- トレーニング中の画面スリープ防止（Screen Wake Lock対応端末）
- セット完了・種目完了・Workout完了時のハプティックフィードバック

### Changed
- 休憩管理をD-logから分離し、Apple Watch等で管理する方針へ変更
- 保存・同期などのメッセージを約2.6秒後に自動消去
- 当直表示を週間予定から削除

### Fixed
- 日本時間で月曜日なのに週間予定の「今日」がずれる問題
- トレーニング開始後に追加した種目へセット欄が作成されない問題

## 6.1.x
- 種目メモ、トレ全体メモ、セット数変更、種目の並び替え・スキップ
- Workout保存前の確認、所要時間・主観評価
- 前回記録表示、前回コピー、RIR、完了セットのみ同期
