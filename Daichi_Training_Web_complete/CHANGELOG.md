# Changelog

## v9.3.4 — Hotfix

### Fixed
- 保存ボタンの連打によるWorkout二重登録をクライアント側で即時ブロック。
- Workout開始時に一意のSession IDを発行し、API側でも同一Session IDの再保存を拒否。
- 履歴編集で種目とセットが常時展開され、並び替えにくかった問題をアコーディオン化。

### Added
- 履歴編集からWorkoutを丸ごと削除可能。重複して作成されたWorkoutの整理に対応。
- 種目名タップでセット編集を展開・収納。

### Changed
- ホーム見出しの「今日はどこやる？」を削除し「D-log」に簡略化。
- 履歴カードは所要時間を優先表示。
