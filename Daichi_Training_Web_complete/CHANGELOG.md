# Changelog

## 8.0.0

### Added
- Weekly schedule editing directly in D-log with a compact calendar-style week view.
- Local schedule persistence, with Notion schedule synchronization when configured.
- User-owned exercise notes that are written back to the exercise master and shown next session.

### Changed
- Removed automatically generated exercise targets and one-line advice from the workout screen.
- Made the current set substantially clearer with a strong border, CURRENT SET label, spacing, and input emphasis.
- Updated draft storage and app version to v8.0.0.

### Notes
- Notion remains the background data store; everyday schedule and note editing happens in D-log.
